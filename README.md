# できたよ！TODOリスト (everyday-tasks)

子供が自主的にTODO（やること）を管理できるシンプルなWebアプリケーションです。

## 特徴
- **タップしやすい大きなUI**: お子様でも押しやすい大きめのボタンと入力フォーム
- **直感的な操作**: タスクを追加し、「できた！」ボタンを押すとできたリストに移動
- **LocalStorage対応**: ブラウザを再読み込みしてもタスクが消えません
- **レスポンシブ**: スマートフォン・タブレット・PCに対応

## 技術スタック
- Next.js (App Router, TypeScript)
- Chakra UI v3
- LocalStorage

## 開発環境の起動手順

```bash
# パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。
